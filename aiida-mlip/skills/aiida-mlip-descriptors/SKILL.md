# AiiDA-MLIP: MLIP Descriptors

Extract invariant representations and latent feature vectors generated by machine-learned interatomic potentials through AiiDA's `mlip.descriptors` calculation job.

## Key Procedures

### 1. Submitting Descriptors Calculation via Python API

```python
from aiida.engine import submit
from aiida.orm import Bool, InstalledCode, Str, StructureData
from aiida.plugins import CalculationFactory
from ase.io import read

atoms = read("structure.cif")
structure_node = StructureData(ase=atoms)
code = InstalledCode.collection.get(label="janus")

inputs = {
    "code": code,
    "architecture": Str("mace_mp"),
    "structure": structure_node,
    "invariants_only": Bool(True),
    "calc_per_element": Bool(True),
    "calc_per_atom": Bool(False),
    "metadata": {
        "options": {
            "resources": {"num_machines": 1},
        }
    },
}

DescriptorsCalculation = CalculationFactory("mlip.descriptors")
calc_node = submit(DescriptorsCalculation, **inputs)
print(f"Submitted Descriptors calculation: PK={calc_node.pk}")
```

### 2. Submitting via CLI Script

```bash
micromamba run -n janus verdi run aiida-mlip/skills/aiida-mlip-descriptors/examples/submit_descriptors.py \
  "janus@localhost" \
  --structure "structure.cif" \
  --architecture "mace_mp" \
  --invariants-only True
```
