# Janus-Core: MLIP Descriptors

Extract internal invariant representations and features generated by machine-learned interatomic potentials (such as MACE) for downstream classification, property prediction, or clustering.

## Key Procedures

### 1. Structure Mean Descriptors

Computes mean invariant descriptor vectors for the entire atomic configuration:
```bash
janus descriptors \
  --arch mace_mp \
  --struct structure.cif \
  --out descriptors.extxyz \
  --device cpu \
  --no-tracker
```

### 2. Per-Atom and Per-Element Descriptors

To inspect local atomic chemical environments or compute species-specific averages:
```bash
janus descriptors \
  --arch mace_mp \
  --struct structure.xyz \
  --calc-per-atom \
  --calc-per-element \
  --out detailed_descriptors.extxyz \
  --no-tracker
```

### 3. Using Python API

```python
from ase.io import read
from janus_core.calculations.descriptors import Descriptors

atoms = read("structure.cif")
desc_calc = Descriptors(
    struct=atoms,
    arch="mace_mp",
    invariants_only=True,
    calc_per_element=True,
    calc_per_atom=True,
)
results = desc_calc.calc()
print("Descriptors computed successfully.")
```
